# Cottage Sort

A cozy sort-and-restore puzzle game. Web-first, built with **Godot 4.7**
(GL Compatibility renderer).

See [DESIGN.md](DESIGN.md) for the concept, monetization, and roadmap.

## Run it

Open the folder in Godot 4.7+ and press **F5**, or from the command line:

```bash
godot --path .
```

Shortcuts while playing: `R` restart, `N` next, `U` undo, `L` levels, `C` cottage, `M` mute.

## Tests

```bash
godot --headless --path . --script res://tools/test_logic.gd
godot --headless --path . --script res://tools/test_daily.gd
```

`test_logic` checks colour counts, that generated levels aren't pre-solved,
independent solvability, and the core move logic. `test_daily` checks the login
curve, spin gating/weighting, and the ad-watch streak.

## Layout

```
game/
  main.tscn        scene entry point
  main.gd          wires board <-> HUD <-> level select; audio, ads, save
  board.gd         SortBoard — draws jars, taps, pour animation, undo, win juice
  hud.gd           GameHUD — top/bottom bars, toast, win overlay
  level_select.gd  LevelSelect — stage grid overlay
  levels.gd        stage list (difficulty knobs)
  level_gen.gd     LevelGen — deterministic, solvable-by-construction generator
  audio.gd         GameAudio — plays game/audio/*.wav
  ads.gd           GameAds — rewarded-ad stub
  save.gd          SaveData — user://save.json
  economy.gd       Economy — coins + cottage upgrade ownership
  cottage_data.gd  CottageData — the first room's slots + tier costs
  cottage_view.gd  CottageView — draws the cottage from upgrade tiers
  cottage_screen.gd CottageScreen — restore screen (view + slots + coins)
  daily.gd         Daily — login cycle, spin, ad-watch streak
  spin_wheel.gd    SpinWheel — the drawn prize wheel
  daily_panel.gd   DailyPanel — the daily rewards / spin screen
  audio/*.wav      placeholder SFX (generated by tools/gen_sfx.py)
tools/
  gen_sfx.py       regenerate the placeholder SFX
  test_logic.gd    headless sanity checks (sort logic + generator)
  test_daily.gd    headless sanity checks (retention logic)
```
