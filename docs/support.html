Common questions

I lost my progress. Progress is stored on your device only, so it does not transfer between devices and is removed if you delete the app. There is no cloud save in this version.

A level seems impossible. Every level can be solved without boosters. Try the Hint button; if you still think a level is broken, email the level number.

How do I stop the ads? This version is ad-supported and has no purchases. Opt-in rewarded videos are always your choice; full-screen ads appear only between levels.
