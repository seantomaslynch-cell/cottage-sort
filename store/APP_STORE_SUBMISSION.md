# Apple App Store submission — checklist

**Building via Codemagic** — see `store/CODEMAGIC.md`. Codemagic runs the macOS
build machines, does code signing, and uploads to App Store Connect / TestFlight,
so **no local Mac is needed**. You still need an **Apple Developer Program**
membership ($99/year) and an App Store Connect API key (added as a Codemagic
integration).

The store-side, one-time setup below (app record, bundle id, IAPs, metadata,
privacy policy, screenshots) is still done by hand in App Store Connect. Once
that's in place, `git push` → Codemagic build → TestFlight is the loop.

## 1. Godot iOS export — handled by Codemagic

`codemagic.yaml`'s `ios-release` workflow installs Godot 4.7.2 + templates,
runs `godot --headless --export-release "iOS"`, signs with the App Store Connect
API key, and uploads to TestFlight. You only need to:

- [x] `application/bundle_identifier` in `export_presets.cfg` set to
      `com.seanlynch.cottagesort` (also in `codemagic.yaml` + `Config.BUNDLE_ID`).
      Still needs registering as an App ID in App Store Connect.
- [ ] Add the native plugins (ads / billing / analytics / notifications — see
      `store/INTEGRATION.md`) and commit them so the CI export picks them up.
- [ ] Configure the Codemagic env groups + integrations per `store/CODEMAGIC.md`.

To build locally instead you'd need a Mac with Xcode + the iOS templates.

## 2. App icon & assets

- [ ] 1024×1024 App Store icon (no alpha, no rounded corners — Apple rounds it).
      Derive from `icon.svg`; the jar-with-beads mark works at 1024.
- [ ] All the smaller icon sizes are generated by Godot's iOS exporter from the
      project icon; verify none are missing in Xcode's asset catalog.
- [ ] Launch screen: Godot generates a storyboard; set its background to the
      cream `#f4ead8` so it matches the boot splash.

## 3. Screenshots (App Store Connect requires these exact sets)

Portrait. Provide at least:

- [ ] **6.9"/6.7" iPhone** (1290×2796 or 1320×2868) — 3 to 10 shots.
- [ ] **6.5" iPhone** (1242×2688) — can reuse scaled if the 6.7" set is present
      on newer tooling; safest to provide.
- [ ] **13" iPad** (2064×2752) if you tick "iPad support" — otherwise iPhone
      only and set the app to iPhone.

Use the 8-shot plan and captions in `store/ASO.md`. Capture from a device or
the simulator at the right resolution; no device frames, no added text beyond
the caption band Apple shows.

Optional: a **15–30s App Preview** video per device size (portrait, captured on
device).

## 5. In-app purchases (create BEFORE submitting the build for review)

In App Store Connect → your app → **In-App Purchases**, create one per SKU in
`Config.IAP_PRODUCT_IDS`, product IDs **identical to `game/iap.gd`**:

| Product ID | Type | Ref name / display |
|---|---|---|
| `remove_ads` | Non-Consumable | Remove interstitial ads |
| `starter_pack` | Non-Consumable | Starter pack |
| `battle_pass` | Non-Consumable (new one per season) or Auto-Renewable if you make it a sub | Season pass |
| `struggle_pack` | Consumable | Struggle pack |
| `booster_bundle` | Consumable | Booster bundle |
| `piggy_crack` | Consumable | Crack the piggy bank |
| `gems_small` / `gems_medium` / `gems_large` | Consumable | Gem packs |
| `coins_small` / `coins_medium` | Consumable | Coin packs |

- [ ] Localized display name + description for each.
- [ ] A screenshot for review (any shot showing the shop).
- [ ] Prices per tier (App Store price points; the $ figures in `iap.gd` are
      just labels — the store's tier is the source of truth).
- [ ] Submit the IAPs **with** the app version (first submission).

## 6. Review

- [ ] **App Review notes:** "Single-player puzzle. No login. Rewarded ads and
      IAP are optional; all levels are completable without them. To test IAP,
      use a sandbox account." Provide a sandbox tester if asked.
- [ ] **Export compliance:** the app uses only standard HTTPS → answer "uses
      encryption" = yes, "exempt" = yes (standard encryption only).
- [ ] **IDFA / App Tracking Transparency:** the ad SDK requests the IDFA →
      you MUST present the ATT prompt before the first ad request, and answer
      the "does this app use IDFA" question = yes, for advertising.
- [ ] Content rights: you own or licensed all art/audio (replace the
      placeholder assets first — see `store/ASO.md`).

## 7. After approval

- [ ] Release manually or auto.
- [ ] TestFlight first for a soft launch is strongly recommended
      (internal + a small external group) to catch device-specific issues
      before a wide release.

## Blocking items to resolve before any of this

1. Apple Developer account + App Store Connect API key (Codemagic provides the Mac).
2. Codemagic env groups + signing set up (`store/CODEMAGIC.md`).
3. Real ad/IAP SDK plugins wired and committed (`store/INTEGRATION.md`).
4. Placeholder art / SFX / music replaced (`store/ASO.md`).
5. A hosted privacy policy page (`store/PRIVACY.md`).
6. The App Tracking Transparency prompt implemented (ties into the ad SDK).
